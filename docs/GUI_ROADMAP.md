# GUI

Implemented (src/gui/gui.c): splash logo, wallpaper, draggable windows, taskbar with clock,
start menu, Terminal (runs the real shell), Files, Notepad, System Info, About.
Drawing API: include/gfx.h (rectangles, lines, text, gradients, alpha, blit).

Ideas next: window resizing, a proper event/widget toolkit, drag and drop in Files,
user programs (needs ring 3 and syscalls), a settings app, 32-bit mouse acceleration.
